# Game Patch

這裡收錄可從原版遊戲重建的補丁、安裝程式、工具版本和驗證紀錄。每款遊戲各有目錄，使用時先核對該目錄的遊戲版本、原版輸入與依賴。

| 遊戲 | 內容 |
| --- | --- |
| [Click Mage](Click-Mage/) | Unity 本機遊戲 API、批次搬運、安裝與還原程式。 |
| [Cypher](Cypher/) | Unity 輔助補丁和本機安裝程式。 |
| [Idle Spiral](Idle-Spiral/) | OpenSpeedy 補丁歷史與原始碼入口。可下載[既有發行版](https://github.com/swear01/idle-spiral-openspeedy-patch/releases/tag/archive-2026-10-24)。 |
| [Kin and Quarry](Kin-and-Quarry/) | Godot 控制腳本、自動採集及引擎實驗。 |
| [Max Manos](Max-Manos/) | Draw 跳幀實驗與從原版檔案重建的工具。 |
| [Minimalism](Minimalism/) | 自動遊玩、路線規劃與驗證工具。 |
| [Minutescape](Minutescape/) | Challenge Patrol 補丁、封裝工具和版本紀錄。 |
| [Outhold](Outhold/) | Godot CLI 與來源封裝工具。 |
| [Particul](Particul/) | Electron 加速和效能修正的腳本與紀錄。 |
| [Shelldiver](Shelldiver/) | Windows 背景 CLI 潛水、轉金、販售與升級。已驗證 800／800 級及吊床結局。 |
| [Sixty Four](Sixty-Four/) | Electron 遊戲 API、加速時鐘修正、安裝、移除及測試。 |
| [Timber Rush](Timber-Rush/) | 依當局數值自動選升級、Banish 及安裝還原程式。 |
| [Unfair Flips](Unfair-Flips/) | 已驗證的 Steam 啟動設定。 |

遊戲原版輸入由各自的安裝取得。第三方工具的版本和取得方式列在各遊戲資料夾。實驗項目的驗證範圍以各自的紀錄為準。
