# Shelldiver 背景自動遊玩

適用 Windows x64 的 Steam App 3862670，實測 build 23898569。PowerShell 控制器透過本機信箱把移動、瞄準和互動交給遊戲內模組。遊戲視窗仍可觀看，玩家可以同時使用桌面滑鼠和鍵盤。採集、轉金、商店入帳和技能購買都由原版遊戲處理。

## 使用順序

1. 保留原有存檔，從自己的 Steam 安裝重建[地形、技能位置和價格表](metadata/README.md)。價格表使用載入模組前的原版執行檔。
2. 依[原生模組說明](native/README.md)建置並安裝與該 build 相符的 Shelldiver 模組，再從 Steam 開啟遊戲。
3. 依[控制器說明](CONTROLLER.md)讀取即時技能目錄，檢查目前計畫，再執行遊玩腳本。已解鎖第十二海域的存檔可使用 1200 公尺路線；其他分支所需的廢料、水晶與蘑菇由對應海域取得。

## 已驗證的結果

原版存檔從 702 級升到 800 級，到結局寫入共 61.94 分鐘，包含中途量測與調整。結局後逐一核對 241 個技能節點，全部達到各自上限。五個分支終點和吊床修復均為 1／1，遊戲播完結局後回到標題畫面。[驗證摘要](verification/native-800-verified-summary.json)

- **升級**按同一貨幣的下一級價格依序選購。一次實測以 1,870,500 黑曜石在 46.83 秒內從 749 升到 780。
- **背包與販售**依存檔中的格數、每格容量、魚種與稀有度判斷能轉入多少。實測每格容量從早期的 16 變成 99。滿包訊號會保留到當趟返航。
- **速度**以牆鐘和原生遊戲步數量測。1200 公尺的一段 5.08 秒連續射擊平均為 182 步／秒。同距離泡泡飛行的中位速度約為原速的 3.05 倍。持續 600 步／秒的目標尚未達到。
